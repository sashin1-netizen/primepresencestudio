# Non-public asset intake

These tracked files were removed from `public/` during the final engineering audit because no matching owner approval and rights record exists. They are source candidates only and are not available from website routes.

Before using any file, confirm provenance and rights, register it in `content/owner-config.json`, generate appropriate derivatives, run `npm run media:validate`, record approval, and publish it only under explicit public-release authority. Starter/template assets should normally be deleted rather than published.

The separately preserved untracked `public/videos/hero-loop.mp4` was not moved or modified.
