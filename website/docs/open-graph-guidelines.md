# Open Graph guidelines

- Default artwork: 1200×630, WebP/JPEG, ≤300 KB, brand mark/tagline only after approval, 80 px safe area, descriptive alt text.
- Each public page inherits its unique title and description. Do not put long copy into artwork.
- A project may use project artwork only when its project record is approved and the image has explicit social-publication rights.
- Store versioned assets under `public/images/social/`; configure width, height and alt in metadata; verify LinkedIn, WhatsApp, Facebook and X previews against the production HTTPS URL.
- Until approved artwork exists, do not manufacture a client/project card or imply work that is not published.
