# Media rights form

Purpose: establish whether each deployed image or video may be published.

For every file record: exact filename, description, page/purpose, creator, source, copyright holder, licence/assignment, permission status, territory/channel restrictions, expiry, client approval reference, approval date and publication status.

Allowed web formats: AVIF, WebP, JPEG, PNG or SVG images; MP4 or WebM video. Recommended limits: images ≤500 KB enforced maximum, case-study target ≤250 KB; video ≤5 MB. Video needs a poster. All informative images need alt text.

Example record: `[filename] — [creator/source] — [rights basis] — [restrictions/expiry] — [approval reference]`. A file without approved permission remains non-public regardless of its content status.
