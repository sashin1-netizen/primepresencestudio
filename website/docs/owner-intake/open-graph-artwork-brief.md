# Open Graph artwork brief

Purpose: provide approved social-share artwork for the default site, optional routes and published projects.

- 1200×630 WebP or JPEG, target ≤300 KB, 80 px safe area
- Descriptive alt text, exact filename and intended route/project
- Creator/source, copyright and social-publication rights
- Brand approval, approval date and publication status

Fallback order: published project artwork → published project-specific override → published default artwork. Draft project art and unapproved route art never enter metadata. Example composition: `[approved mark] + [short approved line] + [restrained background]`; no invented client imagery or claims.
