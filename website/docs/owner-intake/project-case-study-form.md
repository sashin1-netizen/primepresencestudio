# Project case-study form

Purpose: create an evidence-backed Work detail page without developer component rewrites.

- Stable lowercase hyphenated slug, public client name, industry and 3–6 services
- Summary 40–70 words; challenge, strategic direction and execution 80–150 words each
- Deliverables, optional timeline, optional results with evidence source
- Optional approved testimonial, video, website preview, before/after and related published slugs
- Gallery: 1600 px long edge WebP/AVIF/JPEG, preferably ≤250 KB each, filename and alt text
- Video: MP4/WebM ≤5 MB, poster WebP/JPEG ≤250 KB, captions/transcript when content-bearing
- Media manifest, media rights confirmation, client publication approval, approval/publication dates
- Status progression: `draft` → `review` → `approved` → `published`; `rejected` is never public

Example headings: `[Context]`, `[Challenge]`, `[Strategic direction]`, `[Creative execution]`, `[Evidence-backed result]`. At least one visual evidence source is required for publication. Optional fields may remain absent.
