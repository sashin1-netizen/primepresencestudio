# Real-device and responsive checklist

Record device/OS/browser, date, tester, network and pass/fail evidence for each.

## Matrix

- Android Chrome: mid-range handset, normal and slow 4G.
- iPhone Safari: current supported iOS, small and large handset.
- Windows Chrome and Edge: keyboard/mouse, 100% and 200% zoom.
- Tablet portrait and landscape: Safari/Chrome where available.
- OS reduced motion enabled; keyboard only; screen reader spot check.

## Checks

1. Hero image loads without blank flash; title/CTAs visible; no horizontal scroll.
2. Sticky navigation, Menu/Close, Escape, focus containment and rotation work.
3. Every CTA has a 44 px target and visible focus/pressed feedback.
4. Work empty state is truthful; approved project gallery/video/device preview work when content exists.
5. Contact inputs do not zoom unexpectedly, select/keyboard types fit, errors announce, consent and Privacy link work.
6. WhatsApp opens the correct international number/message; email opens a populated draft; test fallback when no mail client exists.
7. Video poster/fallback appears; controls/fullscreen/captions work; no audio autoplays.
8. Footer links, legal routes, Insights and 404 render without clipping.
9. At 200% zoom, content reflows without two-dimensional page scrolling.
10. Slow connection shows usable text/CTAs before non-critical media; no desktop video is forced onto mobile.

Status: not performed in this environment; owner/release tester must complete before public launch.
